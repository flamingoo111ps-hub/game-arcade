## 📞 SUPPORT

### If something doesn't work:

2. Verify all files are present
3. Ensure Flask server is running on port 5000
4. Try clearing browser cache
5. Test in different browser

### Common Issues:

- **No high scores** → Check LocalStorage is enabled
- **Performance lag** → Try Chrome, close other tabs
- **Controls not working** → Verify browser supports input APIs
